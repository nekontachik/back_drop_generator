## Critical Bugs

### BUG-1: sessionStorage key mismatch (AUD-03, FE-03)
- **File:** `frontend/src/components/generate/generate-form.tsx` line 49
- **Issue:** Writes `generate-{id}`, results page reads `job-{id}` — keys never match
- **Impact:** BPM chart and matched styles never display on results page
- **Fix:** Change write key to `job-${res.job_id}`

### BUG-2: colors/shapes data contract mismatch (RAG-02, FE-02)
- **File:** `backend/app/services/rag_retriever.py` + `frontend/src/lib/types.ts`
- **Issue:** Backend stores as comma-strings, frontend expects arrays, `.map()` iterates characters
- **Impact:** Color swatches show garbage, shape tags show individual characters
- **Fix:** Split strings in `rag_retriever.py` before returning

### BUG-3: Hex color parsing crash (pre-existing tech debt)
- **File:** `backend/app/render/effects/tunnel.py` line 18
- **Issue:** `int(h[0:2], 16)` crashes on empty strings
- **Impact:** 2 test failures (`test_sse_progress`, `test_download_after_render`)
- **Fix:** Add empty string guard in hex parsing

### Missing: bpm_override frontend wiring (AUD-04)
- **File:** `frontend/src/components/generate/generate-form.tsx`
- **Issue:** BPM chip selection updates `bpm` field, but backend ignores it when audio present
- **Fix:** Send selected chip value as `bpm_override` FormData field
