## Remaining Bugs

### BUG-4: matched_styles nested/flat data contract mismatch (RAG-02, FE-02)
- **File:** `backend/app/services/rag_retriever.py` `query_styles()` return shape
- **Issue:** Returns `{id, document, metadata: {genre, colors, shapes, ...}, distance}` but frontend `StyleMatch` expects `{id, genre, description, colors, shapes, ..., distance}`
- **Impact:** Style cards render blank in both StylePreview and ResultSidebar — genre, colors, shapes all `undefined`
- **Fix:** Flatten the return dict in `query_styles()`: move `metadata.*` to root level, rename `document` to `description`

### BUG-5: bpm_override never sent on first submit (AUD-04)
- **File:** `frontend/src/components/generate/generate-form.tsx` line 42
- **Issue:** Guard `if (audioFile && detectedBpm)` is always false on first submit because `detectedBpm` is set from response AFTER submit. Form redirects immediately, making second submit impossible.
- **Impact:** User's BPM chip selection (half/double tempo override) is silently ignored. Backend fallback uses detected BPM correctly, so renders work but without override capability.
- **Fix:** Send `bpm_override` whenever `audioFile` is present and user has a BPM value, regardless of `detectedBpm` state. Or: always send the current `bpm` field value as `bpm_override` when audio is attached.
