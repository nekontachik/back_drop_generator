**2. Create backend/scripts/generate_gallery.py** — A Python script that generates gallery example videos by calling the local backend API. The script:

- Defines 6 example configurations matching the EXAMPLES in page.tsx:
  ```python
  EXAMPLES = [
      {"filename": "tunnel-techno.mp4", "prompt": "Neon tunnel pulsing to heavy techno beats", "bpm": 138, "effect": "tunnel"},
      {"filename": "fractal-ambient.mp4", "prompt": "Ethereal fractal morphing in soft ambient hues", "bpm": 72, "effect": "fractal"},
      {"filename": "particles-edm.mp4", "prompt": "Explosive particle storm synced to EDM drops", "bpm": 128, "effect": "particles"},
      {"filename": "plasma-jazz.mp4", "prompt": "Smooth plasma waves flowing with jazz rhythms", "bpm": 110, "effect": "plasma"},
      {"filename": "tunnel-synthwave.mp4", "prompt": "Retro synthwave tunnel with neon grids", "bpm": 118, "effect": "tunnel"},
      {"filename": "fractal-classical.mp4", "prompt": "Elegant fractal bloom following classical dynamics", "bpm": 90, "effect": "fractal"},
  ]
  ```

- For each example:
  1. POST to `http://localhost:8000/generate` with multipart form-data (prompt, bpm, effect, width=1920, height=1080)
  2. Poll GET `/jobs/{job_id}` every 2 seconds until status is "complete" or "failed"
  3. Print progress percentage as it goes
  4. On complete, GET `/jobs/{job_id}/download` and save to `frontend/public/examples/{filename}`

- Uses `httpx` (already a dev dep) for HTTP requests
- Uses `argparse` with `--api-url` flag defaulting to `http://localhost:8000`
- Uses `--output-dir` flag defaulting to `../frontend/public/examples`
- Creates output directory if it doesn't exist
- Prints a summary at the end showing which videos were generated and their file sizes
- Add `if __name__ == "__main__"` entry point
- Add a `--skip-existing` flag that skips generation if the output file already exists

Script should be runnable as: `cd backend && python scripts/generate_gallery.py`
