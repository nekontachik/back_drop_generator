    Create `backend/app/services/job_manager.py`:
    - Module-level `_jobs: dict[str, JobState] = {}` (in-memory store)
    - `def create_job(params: RenderParams) -> JobState`:
      - Generate job_id with `str(uuid4())`
      - Create JobState with status=PENDING, progress=0.0, created_at=datetime.utcnow()
      - Store in _jobs dict
      - Return JobState
    - `def get_job(job_id: str) -> JobState | None`: return _jobs.get(job_id)
    - `def update_job(job_id: str, **kwargs) -> JobState | None`:
      - Get job, update fields from kwargs (status, progress, error, output_path)
      - Return updated job or None
    - `def list_jobs() -> list[JobState]`: return list(_jobs.values())

    Create `backend/app/worker.py` (per D-14, RND-04, Pattern 1 from research):
    - Module-level: `_executor = ProcessPoolExecutor(max_workers=1)`
    - Module-level: `_progress_values: dict[str, multiprocessing.Value] = {}`
    - `def submit_render(job_id: str, params: RenderParams, output_dir: Path) -> None`:
      - Create progress = multiprocessing.Value('d', 0.0)
      - Store in _progress_values[job_id]
      - Compute output_path = str(output_dir / f"{job_id}.mp4")
      - Get the event loop: `loop = asyncio.get_running_loop()`
      - Submit: `future = loop.run_in_executor(_executor, _render_in_process, params.model_dump(), output_path, progress)`
      - Add done callback via asyncio: when complete, update job status to COMPLETE or FAILED
    - `def _render_in_process(params_dict: dict, output_path: str, progress: multiprocessing.Value) -> str`:
      - IMPORTANT: This runs in a CHILD process. Must import everything fresh.
      - `from app.models.params import RenderParams`
      - `from app.render.pipeline import render_video`
      - Reconstruct: `params = RenderParams(**params_dict)`
      - Call: `render_video(params, output_path, progress)`
      - Return output_path
    - `def get_progress(job_id: str) -> float`:
      - Return _progress_values[job_id].value if exists, else 0.0
    - `def cleanup_progress(job_id: str) -> None`:
      - Remove job_id from _progress_values if present

    CRITICAL NOTE: params must be serialized to dict before passing to ProcessPoolExecutor because Pydantic models may not pickle cleanly across process boundaries. Use params.model_dump() on submit side and RenderParams(**params_dict) on worker side.

    Create `backend/app/services/cleanup.py` (per D-18):
    - `async def cleanup_old_renders(render_dir: Path, ttl_seconds: int = 3600) -> int`:
      - Scan render_dir for .mp4 files
      - Delete files older than ttl_seconds (based on mtime)
      - Return count of deleted files
    - `async def start_cleanup_loop(render_dir: Path, ttl_seconds: int = 3600, interval: int = 300) -> None`:
      - Infinite loop: await asyncio.sleep(interval), then run cleanup_old_renders
      - Log deleted count
  </action>

      - Return GenerateResponse(job_id=job.job_id)

      - Get job from job_manager
      - If not found: raise HTTPException(404, "Job not found")
      - Update progress from worker.get_progress(job_id)

      - Use FastAPI built-in SSE: `from fastapi.sse import EventSourceResponse, ServerSentEvent`
      - Async generator: yield SSE events with job status and progress
      - Poll every 0.5 seconds via asyncio.sleep
      - On complete/failed: yield final event and return
      - On job not found: yield error event and return

      - If output_path missing or file doesn't exist: raise HTTPException(404)
