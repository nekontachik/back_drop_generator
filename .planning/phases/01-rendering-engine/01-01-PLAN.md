    - `def create_ffmpeg_pipe(output_path: str, width: int, height: int, fps: int = 30) -> subprocess.Popen`:
      - Command: `ffmpeg -y -f rawvideo -pix_fmt rgb24 -s {width}x{height} -r {fps} -i pipe:0 -c:v libx264 -preset medium -crf 23 -pix_fmt yuv420p -movflags +faststart -loglevel error {output_path}`
      - Returns Popen with stdin=PIPE, stderr=PIPE

    - `def encode_frames(frames_iter: Iterable[np.ndarray], output_path: str, width: int, height: int, fps: int = 30, total_frames: int = 0, progress_value: multiprocessing.Value | None = None) -> str`:
      - Open ffmpeg pipe via create_ffmpeg_pipe
      - For each frame in frames_iter:
        - Ensure frame is contiguous uint8 RGB of shape (height, width, 3)
        - Write frame.tobytes() to pipe stdin
        - If progress_value provided, set progress_value.value = (i+1) / total_frames
      - Close stdin, wait for process, check returncode
      - If returncode != 0, raise RuntimeError with stderr
      - Return output_path
