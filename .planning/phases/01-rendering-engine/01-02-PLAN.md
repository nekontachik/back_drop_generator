    Implement 4 effects. ALL effects MUST:
    - Use @register decorator from effects/__init__.py
    - Implement BaseEffect ABC (render_frame returns uint8 RGB array of shape (height, width, 3))
    - Use ONLY vectorized NumPy (np.meshgrid/np.mgrid) -- NEVER nested for-loops over pixels (Pitfall 4)
    - Use cyclic functions: sin(2*pi*t), cos(2*pi*t) for ALL time-varying parameters (D-15, Pitfall 2)
    - Use the seeded rng parameter for any randomness (D-05)
    - Parse hex color strings from params into RGB arrays using int(hex[1:3], 16) etc.

    **TunnelEffect** (VFX-01, D-03: twist_speed, ring_count):
    - Create coordinate grid with np.mgrid[-1:1:height*1j, -1:1:width*1j]
    - Convert to polar: radius = sqrt(x^2 + y^2), angle = arctan2(y, x)
    - Depth illusion: use 1/radius as depth, modulate with sin(2*pi*t * speed)
    - Rings: pattern = sin(ring_count * (1/radius) + 2*pi*t) -- creates concentric tunnel rings
    - Twist: add twist_speed * sin(2*pi*t) to angle before computing pattern
    - BPM flash: lerp toward accent_color by beat_intensity * intensity
    - Perspective darkening: multiply by (1 - radius) clamped to [0, 1]

    **FractalEffect** (VFX-02, D-03: zoom_rate, c_param):
    - Create complex plane grid: np.linspace centered at 0 for real and imaginary axes
    - Zoom: scale grid by (1 + zoom_rate * sin(2*pi*t)) -- cyclic zoom
    - Julia iteration: z = z^2 + c, where c morphs cyclically: c_real + 0.1*sin(2*pi*t), c_imag + 0.1*cos(2*pi*t)
    - Run 50-100 iterations, track escape count
    - Color map: escape count normalized to [0,1], lerp between bg_color and primary_color
    - BPM flash: boost brightness by beat_intensity * intensity

    **ParticleEffect** (VFX-03, D-03: count, connection_dist, Pitfall 6):
    - CRITICAL: Do NOT accumulate state. Compute particle positions as pure function of t using seeded RNG.
    - Strategy: Generate base positions from rng at init. For each frame, compute offset as function of t:
      - x_offset = amplitude * sin(2*pi*t + phase_per_particle)
      - y_offset = amplitude * cos(2*pi*t * freq_per_particle)
      - where phase_per_particle and freq_per_particle are from rng (fixed per particle)
    - Draw particles as small filled circles (use coordinate distance, not for-loops)
    - Connections: for each pair within connection_dist, draw a line (use vectorized distance matrix)
    - BPM explosion: on high beat_intensity, multiply offset amplitude by (1 + 2 * beat_intensity)
    - Limit particle count to avoid O(n^2) connection check being too slow (cap at 200)

    **PlasmaEffect** (VFX-04, D-03: layer_count, wave_freq):
    - Create coordinate grid with np.mgrid
    - Sum multiple sin/cos layers: for i in range(layer_count):
      - layer = sin(wave_freq * x * (i+1) + 2*pi*t * speed * (i+1)) + cos(wave_freq * y * (i+1) + 2*pi*t * speed * 0.7 * (i+1))
    - Normalize sum to [0, 1]
    - Color: lerp between primary_color and accent_color based on normalized value
    - BPM: modulate wave_freq by (1 + beat_intensity * 0.5) for beat-reactive wave distortion
    - Background blend: lerp with bg_color at low intensity regions

    Create `backend/app/render/pipeline.py`:
    - `def render_video(params: RenderParams, output_path: str, progress_value: multiprocessing.Value | None = None) -> str`:
      1. Import all effect modules to trigger @register decorators:
         `from app.render.effects import tunnel, fractal, particles, plasma, EFFECT_REGISTRY`
      2. Look up effect class: `effect_cls = EFFECT_REGISTRY[params.effect_name]`
      3. Instantiate: `effect = effect_cls()`
      4. Calculate loop: `total_frames, loop_duration = calculate_loop_params(params.bpm, params.fps)`
      5. Build beat envelope: `envelope = build_synthetic_beat_envelope(total_frames, params.bpm, params.fps, loop_duration)`
      6. Create seeded RNG: `rng = np.random.default_rng(params.seed)`
      7. Get effect-specific params dict: `getattr(params, params.effect_name).model_dump()`
      8. Create frame generator function that yields NumPy frames:
         ```
         def frame_generator():
             for i in range(total_frames):
                 t = frame_phase(i, total_frames)
                 frame = effect.render_frame(t, params.width, params.height, effect_params, envelope[i], rng)
                 yield frame
         ```
      9. Call encode_frames(frame_generator(), output_path, params.width, params.height, params.fps, total_frames, progress_value)
      10. Return output_path

    IMPORTANT: The frame generator yields one frame at a time -- never accumulate frames in a list (Pitfall 5: memory exhaustion).
