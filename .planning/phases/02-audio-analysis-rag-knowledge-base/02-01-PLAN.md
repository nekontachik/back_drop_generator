    ```python
    class BpmResult(BaseModel):
        detected: int
        half: int
        double: int

    class MoodVector(BaseModel):
        spectral_centroid: float
        chroma: list[float]  # 12 pitch classes
        rms: float
        onset_strength: float
        labels: list[str]  # ["bright"/"dark", "energetic"/"mellow", "dense"/"sparse"]

    class BpmVisualization(BaseModel):
        onset_times: list[float]
        onset_values: list[float]
        beat_times: list[float]

    class AudioAnalysis(BaseModel):
        bpm: BpmResult
        beat_times: list[float]
        mood: MoodVector
        visualization: BpmVisualization
    ```

    **Step 2: Create `backend/app/services/audio_analyzer.py`** with three functions:

    `validate_audio(audio_bytes: bytes, filename: str | None) -> None`:
    - Raise ValueError if `len(audio_bytes) > 10 * 1024 * 1024` (10MB limit, per D-04)
    - Raise ValueError if filename doesn't end with `.mp3`, `.wav`, `.ogg`, or `.m4a` (per D-01)

    `classify_mood(centroid: float, rms: float, onset: float) -> list[str]`:
    - if centroid > 2500: "bright" else "dark"
    - if rms > 0.1: "energetic" else "mellow"
    - if onset > 2.0: "dense" else "sparse"
    - Returns list of 3 labels

    `analyze_audio(audio_bytes: bytes) -> AudioAnalysis`:
    - Load via `librosa.load(BytesIO(audio_bytes), sr=22050)` -- always 22050 Hz
    - BPM: `tempo_arr, beat_frames = librosa.beat.beat_track(y=y, sr=sr)` then `bpm = float(tempo_arr[0]) if tempo_arr.ndim > 0 else float(tempo_arr)` -- CRITICAL: tempo is ndarray not float (Pitfall 1)
    - Beat times: `librosa.frames_to_time(beat_frames, sr=sr).tolist()`
    - Octave alternatives: `BpmResult(detected=round(bpm), half=round(bpm/2), double=round(bpm*2))` (per D-02)
    - Spectral centroid: `float(np.mean(librosa.feature.spectral_centroid(y=y, sr=sr)))`
    - Chroma: `librosa.feature.chroma_stft(y=y, sr=sr).mean(axis=1).tolist()` -- 12-element list
    - RMS: `float(np.mean(librosa.feature.rms(y=y)))`
    - Onset envelope: `librosa.onset.onset_strength(y=y, sr=sr)`
    - Onset mean: `float(np.mean(onset_env))`
    - Visualization: `BpmVisualization(onset_times=librosa.times_like(onset_env, sr=sr).tolist(), onset_values=onset_env.tolist(), beat_times=beat_times)`
    - Mood: `MoodVector(spectral_centroid=..., chroma=..., rms=..., onset_strength=onset_mean, labels=classify_mood(...))`
