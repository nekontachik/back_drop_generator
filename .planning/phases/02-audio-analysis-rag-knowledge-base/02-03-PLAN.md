    Change the endpoint signature from Pydantic model to individual Form() + File() parameters (per D-08, Pattern 3 from research):

    ```python
    from fastapi import UploadFile, File, Form
    import asyncio
    from app.services.audio_analyzer import analyze_audio, validate_audio
    from app.services.rag_retriever import query_styles, get_collection

    @router.post("/generate", response_model=GenerateResponse)
    async def generate(
        prompt: str = Form(...),
        bpm: int = Form(120),
        bpm_override: int | None = Form(None),
        width: int = Form(1920),
        height: int = Form(1080),
        seed: int | None = Form(None),
        audio: UploadFile | None = File(None),
    ) -> GenerateResponse:
    ```

    Inside the handler:
    1. If `audio is not None`: read bytes with `await audio.read()`, call `validate_audio(audio_bytes, audio.filename)`, then run analysis in thread pool: `audio_analysis = await asyncio.to_thread(analyze_audio, audio_bytes)` (Pitfall 5: blocks event loop otherwise)
    2. Determine effective BPM: `bpm_override or (audio_analysis.bpm.detected if audio_analysis else bpm)` (per D-09)
    3. Validate effective BPM is in 60-200 range, raise HTTPException(422) if not
    4. Query RAG: `try: collection = get_collection(); matched_styles = query_styles(collection, prompt, n_results=3) except RuntimeError: matched_styles = None` (graceful fallback if ChromaDB not initialized)
    5. Call `map_prompt_to_params(prompt, effective_bpm, width, height, seed)` as before
    6. Create job, submit render as before
    7. Return `GenerateResponse(job_id=job.job_id, audio_analysis=audio_analysis, matched_styles=matched_styles)`

    from fastapi import APIRouter, Query
    from app.services.rag_retriever import query_styles, get_collection

    router = APIRouter()

    @router.get("/styles")
    async def styles(
        prompt: str = Query(..., description="Text prompt to match against genre styles"),
        n_results: int = Query(3, ge=1, le=10, description="Number of results to return"),
