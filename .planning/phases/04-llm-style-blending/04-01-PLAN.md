Create `backend/app/services/llm_blender.py` with:

1. **Data class for LLM result** (per D-07):
   ```python
   class BlendResult(BaseModel):
       params: RenderParams
       creative_description: str  # 1-2 sentence description of envisioned visual
       source: str  # "llm" or "fallback"
   ```

2. **Prompt builder function** `_build_prompt(prompt, genre_docs, mood, blend_genres, blend_ratio, bpm)`:
   - System prompt: "You are a creative visual designer for music backdrops. Output ONLY valid JSON matching the schema provided."
   - User prompt includes (per D-06):
     - User's text prompt
     - RAG-retrieved genre docs (full text + metadata for each)
     - Blend instruction: e.g. "Blend 70% Techno + 30% Ambient" with the two genre names and ratio
     - Audio mood context: semantic labels (bright/dark, energetic/mellow, dense/sparse) plus raw values (spectral_centroid, rms, onset_strength)
     - Available effects: ["tunnel", "fractal", "particles", "plasma"]
     - Exact JSON schema with field names, types, and valid ranges:
       - effect_name: one of ["tunnel", "fractal", "particles", "plasma"]
       - bg_color, primary_color, accent_color: hex color strings
       - intensity: float 0.0-1.0
       - speed: float 0.0-1.0
       - creative_description: string, 1-2 sentences describing the visual
     - Explicit instruction: "Interpolate creatively between the genre documents. Do NOT just copy one genre's values. Blend colors, intensity, speed based on the ratio and mood."

3. **`blend_style()` function** — the main entry point:
   ```python
   async def blend_style(
       prompt: str,
       genre_docs: list[dict],
       mood: MoodVector | None,
       blend_genres: tuple[str, str] | None,  # ("Techno", "Ambient")
       blend_ratio: int,  # 0-100, percentage for first genre
       bpm: int,
       width: int = 1920,
       height: int = 1080,
       seed: int | None = None,
   ) -> BlendResult:
   ```
   Implementation:
   - Check `settings.anthropic_api_key`. If None, call `_deterministic_fallback()` and return with `source="fallback"` (per D-10).
   - Build prompt via `_build_prompt()`.
   - Call `anthropic.Anthropic(api_key=settings.anthropic_api_key).messages.create()` with:
     - model="claude-3-5-haiku-latest" (per D-01)
     - max_tokens=1024
     - temperature=0.8 (creative but not wild)
     - The built system + user messages
   - Parse response text as JSON. Extract `creative_description` and render param fields.
   - Validate with `RenderParams(effect_name=..., bg_color=..., primary_color=..., accent_color=..., intensity=..., speed=..., bpm=bpm, width=width, height=height, seed=seed)`.
   - Validate `effect_name` is in `["tunnel", "fractal", "particles", "plasma"]`.
   - If JSON parse fails or Pydantic validation fails: **retry once** with a stricter prompt appending "Your previous response was invalid JSON. Output ONLY a JSON object, no markdown, no explanation." (per D-09).
   - If second attempt also fails: call `_deterministic_fallback()`, return with `source="fallback"`.
   - On `anthropic.APIError`, `anthropic.APITimeoutError`, or any Exception from the API call: log error, call `_deterministic_fallback()`, return with `source="fallback"` (per D-11). Use 30-second timeout.

4. **`_deterministic_fallback()` function** (per D-10):
   - Uses existing `map_prompt_to_params()` from prompt_mapper.
   - If `genre_docs` is not empty, override colors/intensity/speed from the top genre doc's metadata.
   - Returns `BlendResult(params=..., creative_description="Generated using style matching (LLM unavailable)", source="fallback")`.

5. **Logging** — use `logging.getLogger(__name__)` to log:
   - INFO: "LLM blend requested for prompt: {prompt[:50]}"
   - INFO: "LLM blend successful, effect={effect_name}" or "Using deterministic fallback"
   - WARNING: "LLM returned invalid JSON, retrying" (on first failure)
   - ERROR: "LLM blend failed after retry, falling back" with exc_info
   - ERROR: "LLM API error: {error}, falling back"
