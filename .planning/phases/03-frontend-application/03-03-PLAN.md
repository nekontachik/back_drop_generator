Backend SSE stream (GET /jobs/{id}/stream):
- Event name: "progress"
- Data: JSON `{ job_id: string, status: string, progress: number, error: string | null }`
- Status values: "pending", "rendering", "complete", "failed"
- Progress: 0.0 to 1.0 (float)
- Stream ends when status is "complete" or "failed"

Backend download (GET /jobs/{id}/download):
- Returns MP4 file with Content-Type: video/mp4
- 404 if job not complete or file missing

   - SSE connection via useEffect (FE-04):
     ```typescript
     useEffect(() => {
       const es = getJobStream(jobId);
       es.addEventListener("progress", (event) => {
         const data = JSON.parse(event.data);
         setStatus(data.status);
         setProgress(data.progress);
         if (data.error) setError(data.error);
         if (data.status === "complete" || data.status === "failed") {
           es.close();
         }
       });
       es.addEventListener("error", () => {
         // EventSource reconnects automatically, but if server is down, show error
         setError("Connection lost. Refresh to check status.");
         es.close();
       });
       return () => es.close();
     }, [jobId]);
     ```
