    In `frontend/src/components/generate/generate-form.tsx`, in the `handleSubmit` function:
    - Change the bpm_override guard from:
      ```typescript
      if (audioFile && detectedBpm) {
        formData.append("bpm_override", String(bpm));
      }
      ```
    - To:
      ```typescript
      if (audioFile) {
        formData.append("bpm_override", String(bpm));
      }
      ```
    - This sends the user's current BPM field value as bpm_override whenever an audio file is attached, regardless of whether detectedBpm has been set yet. The backend will use this value to override the BPM detected from the audio file. If the user hasn't changed the BPM input, the default value (120) is sent, which is acceptable since the backend's detected BPM will take precedence unless the user actively selected a half/double override chip.
